# TORVEX
**PREPARE. PROGRESS. PREVAIL.**

TORVEX is an installable PWA starter for a premium academic command centre.

## Requirements
- Node.js 20+
- npm

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Deploy
Deploy the project to an HTTPS static host (for example GitLab Pages or another static hosting provider). The manifest and service worker provide the PWA foundation.

## Current starter scope
- Responsive dashboard shell and navigation
- TORVEX visual direction: midnight navy, graphite, silver and controlled racing red
- PWA manifest and basic service worker
- Placeholder mission state; no fake study metrics

## Important
This is the first runnable foundation, not the complete approved TORVEX product. Authentication, secure AI backend, planner logic, study tracking, reports, 3D vehicle assets, Spotify OAuth and push notifications still need implementation. Do not add API keys to frontend files.
